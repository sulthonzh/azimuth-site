azimuth

The OS where apps physically cannot do what you didn't authorize.

Download GitHub Documentation

Capability Security

Every app gets explicit capabilities, not blanket permissions. An app can't read your files, access the network, or talk to hardware you didn't grant it access to. Enforced by the kernel, not by promises.

Budget Accounting

Apps can't starve the system. CPU time, memory, and I/O are budgeted per app. A runaway process hits its ceiling and stops — your other apps keep running.

Linux Drivers

Runs the entire Linux driver ecosystem (15M+ lines) through an isolated driver cell. WiFi, GPU, USB, NVMe — if it works on Linux, it works on azimuth.

Written in Rust

Memory-safe by construction. No buffer overflows, no use-after-free, no data races. The entire kernel is Rust with unsafe forbidden by default.
